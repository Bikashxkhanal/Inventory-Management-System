## 🔥 Overview

The **Inventory Management System (IMS)** is a **full-stack SPA** built to manage products, stock, orders, and analytics.  

It emphasizes **separation of concerns**, with a **React frontend** consuming **REST APIs** from an **Express backend**, and uses **MongoDB** as a database.  

Designed with **Client-Side Rendering (CSR)**, it provides **smooth navigation** and **dynamic rendering** for modern web apps.  

---

## 🛠️ Core Features

### **1. User Management**
- Role-based access control: **Admin**, **Staff**, **Customer**  
- Secure authentication using **JWT**  
- User sessions with proper authorization for routes  

### **2. Product & Inventory Management**
- Add, update, delete, and view products  
- Track inventory, stock levels, SKU, and categories  
- Real-time updates reflected on the dashboard  

### **3. Orders & Transactions**
- Create, update, and manage orders  
- Generate invoices automatically  
- Track sales history and order details  

### **4. Dashboard & Analytics**
- Real-time stock and sales overview  
- Insightful charts and metrics for better decision making  

### **5. Search & Filtering**
- Search products by **name**, **category**, or **SKU**  
- Filter by **stock status**, **price**, or **availability**  

### **6. SPA & CSR**
- Client-side routing for smooth navigation  
- Dynamic content updates via API calls without page reload  

### **7. Responsive UI**
- Fully responsive design using **Tailwind CSS**  
- Optimized for desktop, tablet, and mobile
